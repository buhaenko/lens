Is it safe?

It’s open source

Every line of Lensy is on GitHub. Each release is built and tested by GitHub Actions straight from that code, so the app you download is the code you can read.

What it can access — and why
  • Screen Recording — to read the text inside the area you select — only when you scan.
  • Accessibility — to notice the quick-scan key (a modifier you tap on its own). Lensy never reads what you type.

macOS asks you first; Lensy is already in the list, you just flip the switch. You can turn it off any time in System Settings → Privacy & Security.

Does it send my data anywhere?

Lensy never sends your text or screen anywhere. Network access: macOS downloading a language pack from Apple the first time you translate into a new language, a daily check on GitHub for a new version of Lensy (you can turn it off in Settings), and — only when you use Send Feedback… — the email and message you type there. No analytics in the app, no accounts, no tracking. This website counts visits anonymously with Cloudflare Web Analytics — no cookies, nothing that identifies you.

Why doesn’t macOS say “verified developer”?

Apple charges $99 a year for that badge. Lensy is a free side project, so it’s signed locally instead. The Terminal command installs it without any warning. With the DMG, macOS asks once — click Open Anyway in System Settings → Privacy & Security.

How do I check the download?

Compare the SHA-256 of the file with the one published on the release page:

shasum -a 256 ~/Downloads/Lensy.dmg
see the release page

How do I uninstall it?

Quit Lensy from its menu and drag it from Applications to the Trash — or run
curl -fsSL https://getlensy.app/install.sh | bash -s -- uninstall

Anything else I should know?

The first translation into a new language downloads a language pack from Apple once; after that it works offline. Every scan is kept in a searchable history in the menu bar — pin the ones worth keeping.
